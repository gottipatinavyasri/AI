# EduPath AI source folder

This `src/` folder contains copies of the main HTML/CSS/JavaScript source files for convenient editing.

Important: This project is a plain HTML/CSS/JavaScript static website, not a React/Vite project. The existing deployment uses the original root files (`index.html`, `styles.css`, and `js/`). Keep those original files in place for the current Netlify/Vercel configuration. The `src/` copies are provided for source organization and are not used by the current deployment.
